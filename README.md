# Kivi-Autoclicker
A Basic, lightweight C++ Autoclicker.

---

## Features
- Minimal CPU Usage
- Start/Stop clicking with Hotkeys
- Toggle between Left and Right click
- Runs at 10-12 CPS with Randomized Intervals

---

## Controls
| Key | Action |
|-----|--------|
| `X` | Start Clicking |
| `V` | Stop Clicking |
| `Q` | Quit Autoclicker |
| `R` | Toggle Left or Right Click |

---

Double-click `kivi.exe` to use.
