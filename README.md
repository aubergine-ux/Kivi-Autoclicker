# Kivi-Autoclicker
A Basic, lightweight C++ Autoclicker.

---

## Features
- Start/Stop clicking with Hotkeys
- Runs at 10-12 CPS
- Minimal CPU Usage

---

## Controls
| Key | Action |
|-----|--------|
| `X` | Start Clicking |
| `V` | Stop Clicking |
| `Q` | Quit Autoclicker |

---

Double-click `kivi.exe` to use.
